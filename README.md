# 🧬 ScoreOrbit · 生物合格考助手

> 沪教版高中生物 | 156个核心知识点 | 合格考复习工具

## 📖 简介

ScoreOrbit 是一款专为沪教版高中生物合格考设计的本地复习工具，包含：

- 📚 **156个核心知识点** - 覆盖必修1和必修2全部内容
- 📝 **1099道填空题** - 知识点填空练习
- 📄 **历年真题 + 模拟卷** - 可直接查看和下载（试卷需单独获取）

## 🚀 快速开始

### 方法一：直接运行（推荐）

1. 下载本仓库
2. 双击 `一键启动.bat`
3. 浏览器自动打开，开始使用

**无需安装 Python，已内置虚拟环境！**

### 方法二：获取试卷包

由于版权原因，试卷文件不包含在公开仓库中。

需要的同学请联系作者获取试卷包，解压后放入 `data/exams/试卷/` 目录。

## 📱 手机/平板访问

1. 电脑上运行程序后，查看命令行显示的地址（如 `http://192.168.x.x:8501`）
2. 手机连接同一 WiFi
3. 浏览器输入该地址即可访问
