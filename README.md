# 🎓 ScoreOrbit · 合格考助手

> 沪教版高中 | 六大学科 | 752个知识点 | 421套试卷

## 📖 简介

ScoreOrbit 是一款专为沪教版高中合格考设计的本地复习工具，涵盖**生物、物理、化学、历史、地理、政治**六大学科。

## ✨ 功能特点

- 📚 **752个核心知识点** - 覆盖六大学科全部内容
- 📝 **历年真题 + 模拟卷** - 421套试卷资源
- 🎯 **知识点搜索** - 快速定位
- 📊 **学习统计** - 进度追踪
- 📱 **手机访问** - 局域网内手机浏览器访问

## 🚀 快速开始

### 方法一：直接运行（推荐）

1. 下载本仓库
2. 双击 `一键启动.bat`
3. 浏览器自动打开，选择学科使用

**首次运行会自动安装依赖，请耐心等待**

### 方法二：获取试卷包

由于版权原因，试卷文件不包含在公开仓库中。

请联系作者获取试卷包，解压后放入各学科的 `exams/试卷/` 目录。

## 📱 手机/平板访问

1. 电脑上运行程序后，查看命令行显示的地址（如 `http://192.168.x.x:8501`）
2. 手机连接同一 WiFi
3. 浏览器输入该地址即可访问
